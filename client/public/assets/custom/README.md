# VirtualOffice Custom Asset Pack

Pack d'assets original créé pour le prototype VirtualOffice.

Contenu :
- tiles/office_tileset_32x32.png
- tiles/office_tileset_32x32.tsx
- furniture/office_furniture_64x64.png
- decor/office_decor_32x32.png
- avatars/avatar_basic_32x48.png
- docs/manifest.json

Style :
- pixel-art top-down détaillé
- bureau moderne / chaleureux
- pensé pour Tiled + Phaser

Organisation Tiled recommandée :
1. Floor
2. FloorDecor
3. Walls
4. Windows
5. Doors
6. FurnitureBottom
7. Furniture
8. FurnitureTop
9. Plants
10. WallDecor
11. Collision
12. Spawn
13. Zones

Important :
- les tuiles de base font 32x32
- le mobilier est placé dans des cellules 64x64 pour permettre plus de détails
- l'avatar de démonstration est en 32x48
- ces assets sont originaux et destinés à servir de base au projet

Tu peux donner directement ce dossier à Codex pour construire la map Tiled.
